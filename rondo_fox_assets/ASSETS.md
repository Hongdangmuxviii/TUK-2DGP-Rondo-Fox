- 칼 궤적은 그림에 없음. effects/pixelfx/sword-slash-rondo로 그림.
- 2단 라인: 위 줄 공격은 같은 fox_ground를 위 줄 높이(아래 줄 발 높이 - 190 px)에 그리고, 이동 순간은 반투명 잔상 2개로 표현.
- 원본은 GPT 이미지 생성, 후처리(투명도 정리, 빨간 테두리 번짐 제거, 크기·위치 보정)를 거친 버전임.

```python
def draw_frame(image, index, cols, rows, x, y, fw=456, fh=448):
    col, row = index % cols, index // cols
    image.clip_draw(col * fw, (rows - 1 - row) * fh, fw, fh, x, y)   # pico2d: y=0이 아래
```

```python
BG_SCALE = 720 / 1024
def draw_bg(image, tile_w, scroll):
    w = int(tile_w * BG_SCALE)
    x = -(scroll % w)
    while x < 1280:
        image.draw_to_origin(x, 0, w, 720)
        x += w
```

## music/ (스테이지 음악 + 채보)
- `stage1_intro.mp3` 서주 (54 BPM, 약 40초), `stage2_rondo.mp3` 론도 (138 BPM, 약 102초), `stage3_coda.mp3` 코다 (130 -> 170 BPM, 약 70초).
  - REAPER에서 바이올린 Violin One + 피아노 Piano Uno로 렌더링. 앞 공백을 잘라 음악 첫 음이 0초.
- `charts/stageN_*_chart.json`: `{"offset":0.0,"audio":"...mp3","notes":[{"t":초,"lane":"up"|"down","type":"tap"|"long","end":초}]}`
  - `t`는 mp3 재생 시작 기준 초. up = F(위 줄), down = J(아래 줄). long은 `end`까지 누르기(타이).
  - 노트 수: 1스테이지 16, 2스테이지 107, 3스테이지 112.
- `midi/*.mid`: 렌더링에 쓴 원본 MIDI (셈여림은 velocity에 반영). 음색 다시 뽑을 때 사용.
- 주의: 3스테이지는 렌더링 때 170 BPM 전환이 14박 늦게 걸려서, 그 구간 채보 시간을 음원에 맞춰 옮겨 둠. MIDI로 다시 렌더링하면 채보도 다시 맞춰야 함.
