- 원본은 GPT 이미지 생성, 후처리(투명도 정리, 잡티 제거, 크기·위치 보정)를 거친 버전임.

```python
FW, FH = 456, 448
def draw_frame(image, index, cols, rows, x, y):
    col, row = index % cols, index // cols
    image.clip_draw(col * FW, (rows - 1 - row) * FH, FW, FH, x, y)   # pico2d: y=0이 아래
```

## background/ (스테이지 배경, 가로 반복 타일)

공통: 높이 1024, 바닥 윗선은 위에서 781 px (세 장 동일). 1280x720 화면에서는 720/1024 배로 축소해서 가로로 이어 그림.
캐릭터 발 높이는 화면 아래에서 y = 120. 스크롤 속도는 노트 속도의 약 0.4배 권장. game_world layer 0.

| 파일 | 스테이지 | 타일 폭 |
|---|---|---|
| bg_stage1.png | 1스테이지 객석 | 966 |
| bg_stage2.png | 2스테이지 붉은 무대 | 992 |
| bg_stage3.png | 3스테이지 금빛 무대 | 1462 |

```python
BG_SCALE = 720 / 1024
def draw_bg(image, tile_w, scroll):
    w = int(tile_w * BG_SCALE)
    x = -(scroll % w)
    while x < 1280:
        image.draw_to_origin(x, 0, w, 720)
        x += w
```
